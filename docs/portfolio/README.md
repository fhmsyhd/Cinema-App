# Cinema App Portfolio Pack

This folder contains the finalized materials for presenting Cinema App on Upwork and a personal portfolio website.

## Files

| File | Purpose |
| --- | --- |
| `cinema-app-demo.mp4` | User-recorded 35-second application demo |
| `cinema-app-cover-1000x750.png` | Primary Upwork cover image |
| `cinema-app-flow-1000x750.png` | Product flow: Discover, Explore, Save |
| `cinema-app-engineering-1000x750.png` | Architecture and engineering overview |
| `cinema-app-website-hero-1600x900.png` | Hero image for the portfolio website |
| `upwork-portfolio-copy.md` | Copy-ready Upwork title, role, description, and captions |
| `case-study.md` | Full website case study and demo storyboard |

## Recommended Upwork order

Use this order when adding content blocks:

1. `cinema-app-cover-1000x750.png`
2. Short overview text from `upwork-portfolio-copy.md`
3. `cinema-app-demo.mp4`
4. `cinema-app-flow-1000x750.png`
5. Product-flow caption from `upwork-portfolio-copy.md`
6. `cinema-app-engineering-1000x750.png`
7. Engineering caption from `upwork-portfolio-copy.md`

If Upwork offers the option to use the video as the portfolio cover, use the video only when its opening frame clearly shows the application. Otherwise, keep the dedicated cover image first.

## Recommended website order

1. Use `cinema-app-website-hero-1600x900.png` as the project hero.
2. Use the **Overview**, **Challenge**, **Solution**, and **Architecture** sections from `case-study.md`.
3. Place the three vertical screenshots from `../screenshots/` inside the solution section.
4. Embed `cinema-app-demo.mp4` after the overview.
5. End with the source-code link and the **What I would improve next** section.

## Accessibility text

- **Cover:** Cinema App Android case study showing the home, movie detail, and favorites screens.
- **Product flow:** Three Cinema App screens illustrating movie discovery, detail exploration, and saving a favorite.
- **Engineering:** Cinema App home screen beside a layered architecture diagram from UI to REST API and Room.
- **Website hero:** Cinema App portfolio hero showing three Android application screens.

## Publishing checklist

- Use the field values and captions from `upwork-portfolio-copy.md` for the Upwork form.
- Do not place email addresses, phone numbers, or social-media handles inside Upwork media.
- Confirm the GitHub repository is public before adding its link.
- Preview every image after upload to confirm Upwork did not crop important content.
- Keep the video in MP4 format and below the platform limit.
- Use the dedicated website copy when publishing outside Upwork.
